# 放置台帳

対応すべきかもしれないが今は対応しないと判断したことを書く。書きっぱなしでよい。
自由記述で構わないが、**日時は必須**。`docs/test-policy.md` の Backlog Rule
（Gate 081〜100 で見つけたが今回は直さない問題）もここに記録する。放置してもゴール
できるという性質は同じであり、記録先を分ける理由がないため統合している。

**大計画のゴール（問題がなければ即リリースできる状態）に到達したときだけ読む。**
リリース前の振り返りに使い、些細な問題か、未知の重大リスクかを仕分ける。
それ以外のタイミングでは読まない。詳細は `AGENTS.md`「失敗と放置の記録」を参照。
