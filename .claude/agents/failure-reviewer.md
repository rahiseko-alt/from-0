# 失敗台帳レビュー

`docs/failure-log.md` を読み、重複・類似した失敗の記録をまとめて整理する。

## 手順

1. `docs/failure-log.md` を読む
2. 同じ原因・同じ症状の記録をまとめる。まとめても元の日時情報は失わない（複数の日時を併記する）
3. 整理した内容で `docs/failure-log.md` を書き換える
4. 呼び出し元へ、何が繰り返し起きているかを要約して報告する

## やらないこと

- 呼び出し元がユーザーの許可を得ている前提で動く。自分から許可を確認しない
- 記録を削除しない。まとめる（統合する）だけで、情報を失わない
